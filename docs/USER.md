# User guide

1. Open the site.
2. Optional: create an account (name, email, password of 10+ characters).
3. Open the Kimironko seed to see a finished kit with one blank oil line.
4. After login, photograph a notebook or type lines. Unclear amounts stay blank.
5. Tap YES to record consent. Kora still does not send money. A PayPal draft may appear if sandbox keys are set.
6. Dashboard lists your kits. Search by stall or place. Edit notes or delete a kit you own.

The public seed is not a customer. Kora never messages Mama Uwase.
